## 各作品说明

### 01-1 第三棵梧桐（84 秒 · 旗舰作品）

三棵梧桐下的球场、一本褪蓝色的旧课本、一朵压干的雏菊，和一段没有说出口的告别。

- **生成**：MiniMax H3（ref2va）· ComfyUI · 8 步 turbo LoRA
- **流程**：人物三视图 + 空景板定锚 → 逐镜 1024×576 生成 → 上一镜尾帧当下一镜首帧接力 → Real-ESRGAN 2× 超分 → 100 BPM 网格重剪 53 刀 → Resolve FileLUT 调色
- **交付**：1920×1080 / 24 fps / 2016 帧 / 84.000 s / H.264 CRF16 / −12.9 LUFS / −1.5 dBTP
- **成本记录**：40+ 次单镜重渲，单镜 100–390 s
- **文档**：`最终版提示词_V9.docx`（逐镜提示词、人物/场景锚点、负向清单、后期链）、`修改问题归纳.docx`（A–F 六类问题、量化记录、5 条未解决项）

### 01-2 海洋与鲸豚（41 秒）

航拍俯视与水下侧向两个视角交替，鲸豚浮出水面换气又潜回光柱。遮幅 2.39:1，冷蓝主调，只用水的运动推进。
1920×1080 · 24 fps · H.264 15.9 Mbps · PCM 24 bit / 48 kHz。

### 01-3 雪夜街头（17.5 秒 · 过程片段）

雪夜街口、便利招牌、一个走进灯光的背影。低机位手持，颗粒与噪点保留。原始文件仅 960×656，按「过程片段」陈列。

### 02 电影感人像（6 张）

同一人物的两组横向静帧，同一套学院制服、同一阵风，换两个空间：海岸道口的暮色（3 张）与乡野公路的巨云（3 张）。1344×896。

### 03 海报设计 Amor Fati（4 版）

标题字内填充日落云层，手绘线条少女出框压住画面，中部横向实拍条带。四版：云与飞鸟（9:16 / 3:4 两种尺寸）、城市日落、城市日落浅调。

> 「And we should consider every day lost on which we have not danced at least once.」——尼采

### 04 史诗关键帧 龙与骑手（4 张）

焦土、巨龙、白衣骑手，按叙事顺序排列：涉水 → 巨影压境 → 龙首俯瞰 → 烈焰近身。1456×816 · 2.39:1。
